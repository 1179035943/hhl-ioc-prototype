# 红花岭 IOC 完整 HTML 原型

发布版本：2026-11-13-bim-device-review。此仓库为公开原型交付库，不是原型编辑母版。

## 查看

每个发布版本在同一浏览器首次打开时自动显示更新说明，关闭后不再重复；左下角“更新说明”可随时回看。换浏览器、清理存储或使用隐私模式可能再次提示。此组件只在在线发布外壳使用，本地业务母版和离线单HTML不变。

在线预览：[打开完整九屏原型](https://1179035943.github.io/hhl-ioc-prototype/prototype/)。

也可下载 [prototype/index.html](prototype/index.html)，保存到本地后用 Chrome 或 Edge 打开。CSS、脚本、图片均内嵌，无需部署或安装依赖。顶部菜单可切换九屏。

包含：综合态势、产业运营、垂直交通、能源态势、安防态势、应急态势、通行态势、设备态势、环境态势。

## 分享

本次接入提示修订：按已确认设备及来源限制相关详情、关联告警与普通视频下钻，显示“暂未接入”。左右固定展示不变。通力/三菱电梯、建工光伏按明确来源分支区分，泛电梯/泛光伏不推断；AI摄像头和巡防视频不自动归入普通视频安防来源。来源映射尚未明确的对象不伪造入口。未接入不等同零值、离线、无权限或暂无数据。

经所有者确认，本仓库及网页预览公开，任何人均可查看、下载或转发原型；访问不需要 GitHub 账号。请勿向此公开库提交生产密钥、真实个人资料或未获准公开的项目文件。

## 边界

当前为本地模拟交互原型，不代表真实数据、视频、BIM 或无人机起飞/返航接口已接入。原型修改先更新唯一母版，再重新导出本仓库交付文件，不直接改成品。

大小与 SHA256 见 [prototype/version.json](prototype/version.json)。

## 以后发布

先按原流程完成母版修改、完整HTML生成和验收，再更新业务版本清单。每次编辑 prototype/release-notes.json 的发布id、日期、“改了什么”和“去哪里看”，然后运行 `node scripts/prepare-release.cjs <已验收完整HTML>`，验收发布外壳后提交。脚本把说明嵌入实际HTML，并给说明脚本加内容指纹，避免旧页面读取另一版本的说明；不直接编辑九屏内嵌业务。固定网址不变。
