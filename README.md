# 红花岭 IOC 完整 HTML 原型

版本：2026-11-02。此仓库为私有交付库，不是原型编辑母版。

## 查看

下载 [prototype/index.html](prototype/index.html)，保存到本地后用 Chrome 或 Edge 打开。CSS、脚本、图片均内嵌，无需部署或安装依赖。顶部菜单可切换九屏。

包含：综合态势、产业运营、垂直交通、能源态势、安防态势、应急态势、通行态势、设备态势、环境态势。

本版包含最新无人机执行记录/工作台、机器狗“待定”水印，以及应急物资七类统计、具体物资名称和库存地图标签等母版改动。

## 分享

仅仓库所有者和获授权的协作者可访问本仓库。请勿公开仓库或部署为公开网页。仅需查看原型时，可将单 HTML 文件发给指定同事；接收人可以继续转发文件，请按项目保密要求分发。

## 边界

当前为本地模拟交互原型，不代表真实数据、视频、BIM 或无人机起飞/返航接口已接入。原型修改先更新唯一母版，再重新导出本仓库交付文件，不直接改成品。

大小与 SHA256 见 [prototype/version.json](prototype/version.json)。
